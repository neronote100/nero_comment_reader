# 画面設計と要件対応

## 主要画面

| 画面           | 表示と操作                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------------ |
| ログイン       | Googleでログイン・Gmail同意。管理者以外は拒否                                                                |
| 今日の紹介候補 | 会員数・記事数・未紹介人数、入会順/おすすめ度切替、最大6人の候補、30日以上の未紹介一覧                       |
| 記事を探す     | 名前・記事名検索。記事カードから本文・分析を開く                                                             |
| 記事詳細       | 原文リンク、本文、スキ・コメント、企画参加/お気に入り、AI生成、紹介案/コメントのコピー、掲載URL登録          |
| メンバー管理   | 入会順一覧、新規登録、名前・ID・URL・Discord・タグ・優先度・入会日・状態・プラン編集、曖昧なメール通知の確認 |
| 週間ランキング | 公開7日以内。スキ/コメント/総合切替                                                                          |
| 急上昇         | 約7日前の実測との差分と増加率。記録不足と基準0を区別                                                         |
| 紹介履歴       | 掲載日・会員名・記事名・掲載URL                                                                              |
| 連携・収集状況 | Google/AI/Discordの設定、最終同期・通知、手動同期、待機処理、失敗理由・再試行                                |

PCは左ナビ＋カード、スマートフォンは横スクロールナビ＋1列カード。記事とメンバー編集は詳細パネル。外部リンクは新しいタブで開き、本文はReactのテキストとして描画する。

## 操作の流れ

1. Gmail同期で会員を取得。確認待ちはnote IDと通知種別を確認して反映。
2. 入会順・未紹介モードで6人分の候補を確認。
3. note原文と取得本文を読み、AIの具体的な根拠・引用一致を確認。
4. 紹介文・コメントをコピーして必要に応じて加筆。自動投稿はしない。
5. 実際に紹介記事を掲載したらURLを登録。ここで初めて紹介済みにする。

## 要件対応

| 要件       | 実装                                                                             |
| ---------- | -------------------------------------------------------------------------------- |
| F001       | Gmail readonly、入退会・プラン通知解析、順序・重複対応、曖昧なものは確認待ち     |
| F002       | 会員管理API・編集画面・紹介日                                                    |
| F003       | Cron6時/18時、一覧・本文・件数・タグ・画像・日時、D1保存                         |
| F004〜F005 | Structured Outputsで概要・要約・魅力・おすすめ・想定読者・良かったところ         |
| F006       | 公開7日以内のスキ/コメント/総合                                                  |
| F007       | 日次スナップショット、スキ/コメントの増分・率。公開閲覧数は未取得                |
| F008       | 定量スコア＋過去履歴＋企画参加＋AI内容評価、1人1枠、理由・紹介ポイント・引用候補 |
| F009〜F010 | 紹介文・5行程度の自然な王子コメント案、コピー                                    |
| F011       | activeで未紹介、または最終紹介から30日以上                                       |
| F012       | 指定式、AI評価0〜5、企画参加とお気に入りは手動                                   |
| F013       | 朝7時Discordレポート、設定済み時のみ送信、最終結果表示                           |
| V2         | 自動での紹介記事全体作成・公開は今回の対象外                                     |

初回受入では通知メールの実書式、入会順、既知の記事・スキ数、AI出力、Google権限、7日後の成長比較、Discord受信を確認する。外部連携の実認証はセットアップ完了後に必要。
