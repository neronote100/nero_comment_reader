# 王子 Comment Reader 🌙

note「nero_notelover」専用の未返信コメント管理サイトです。

## できること

- 王子の記事一覧を取得
- コメントがある記事だけコメントスレッドを確認
- 王子の最後の返信より後にある他ユーザーのコメントを未返信として抽出
- 未返信コメントを新しい順に一覧表示
- ChatGPTへ相談用プロンプトをワンタップでコピー
- noteの記事をすぐ開ける
- GitHub Actionsで定期同期
- GitHub Pagesで表示

AI API、Cloudflare、有料DBは使いません。
